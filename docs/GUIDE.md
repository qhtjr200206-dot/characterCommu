# 🔍 조사 시스템 (Investigation System) 가이드

이 문서에서는 AI 보조 조사 시스템과 관리자 직접 진행 기능을 설명합니다.

## 1. 새 조사 생성 (AI 스크립트)
- **위치**: `조사 게시판 > 새 조사 생성`
- **프로세스**: 
  1. 제목 및 인원(1인/다인) 설정
  2. 주요 조사 포인트와 발견 가능한 아이템 정의
  3. **AI 스크립트 생성 ✨**: 입력한 설정을 바탕으로 Gemini AI(2.5 Flash)가 분기점과 선택지가 포함된 1~2시간 분량의 시나리오를 자동 생성합니다.
  4. 생성된 스크립트는 직접 편집하거나 확정하여 저장할 수 있습니다.

## 2. 조사 진행 (2가지 모드)
조사방 상단에서 진행 방식을 실시간으로 전환할 수 있습니다.

### A. AI 스크립트 모드
- 준비된 시나리오 장면에 맞춰 시스템이 내레이션을 출력합니다.
- 플레이어는 화면에 뜨는 **선택지 버튼**을 눌러 행동을 결정합니다.
- 선택 시 AI가 설정한 즉각적인 반응(Reaction)이 출력되며 시나리오가 진행됩니다.

### B. GM 직접 진행 (Admin Mode)
- 관리자가 상단의 **[GM 직접진행]** 버튼을 활성화합니다.
- 관리자가 채팅창에 입력하는 내용은 일반 채팅이 아닌 **[GM Script]** 배지가 달린 강조된 텍스트로 모든 참가자에게 전달됩니다.
- 오프라인 TRPG처럼 자유로운 시나리오 핸들링이 가능합니다.

# ⚙️ 관리자 설정 가이드

관리자(Admin) 권한을 가진 계정은 사이트 전체의 스타일과 환경을 제어할 수 있습니다.

## 1. 사이트 기본 설정
- **App Name**: 브라우저 상단 탭과 메인 로고에 표시될 사이트 이름 설정
- **Theme Color**: 사이트의 포인트 컬러(Hex Code) 변경
- **Font Family**: 기본 서체 선택

## 2. BGM 및 분위기 제어
- **배경 음악**: 유튜브 URL을 입력하여 사이트 전체 또는 특정 섹션의 배경 음악을 설정할 수 있습니다.
- **볼륨**: 사이트 초기 진입 시 기본 볼륨을 조절합니다.
